# Linear Regression From Scratch

Implementation of Linear Regression using Gradient Descent — built without scikit-learn.

## What it does
- Implements Gradient Descent manually using NumPy
- Tracks Cost (MSE) across all iterations
- Visualizes prediction line and cost curve side by side

## Technologies
- Python
- NumPy
- Matplotlib

## How to run
```bash
python tree.py
```

## Output
- Prediction lines improving over 1000 iterations
- Cost decreasing from ~950 to near 0
